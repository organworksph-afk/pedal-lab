OrganWorks Pedal Lab: pipe samples
==================================

These 12 files come from the GrandOrgue demo sample set
(packages/demo-*.orgue in https://github.com/GrandOrgue/grandorgue).

Ranks used: Bourdon 8' (also played an octave down as Soubasse 16'),
Montre 8', and Trompette 8' (played an octave down as Bombarde 16').
One sample per octave (F#1, F#2, F#3, F#4); the page re-pitches them
to each pedal note.

Changes made: decoded from WavPack, mixed to mono, resampled to 32 kHz,
trimmed before the release, and given a crossfaded sustain loop. The
loop points are listed in index.html (the SAMPLES table).

These modified files are shared under the same CC BY-SA 2.5 licence.
