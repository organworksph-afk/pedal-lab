# OrganWorks Pedal Lab

Workshop tool for OrganWorks PH: test 32-note MIDI pedalboards with real pipe sound, keep customers, make quotations and invoices, track income and expenses, check Arduino output, and program the ESP32-S3 controller.

Live site: https://organworksph-afk.github.io/pedal-lab

- Open in Chrome or Edge to test a pedalboard over USB MIDI.
- Customers, quotes and accounting are saved in the browser you use (export CSV for backups).

Pipe samples: GrandOrgue demo sample set, recordings by Lars Palo, © GrandOrgue contributors, CC BY-SA 2.5 (SE) / GPL-2.0-or-later. See `samples/README.txt`.
